# 實機錄屏投放區（可選，但大加分）

把手機錄好的四段直式錄屏丟進這個資料夾，檔名照下面取，放好跟我說一聲，我會自動偵測並重 render 兩支影片，把 PC 重建畫面換成真實手機畫面。

| 檔名 | 內容 | 建議長度 |
|---|---|---|
| `phone-wall.mp4` | 長輩版動態牆，慢慢滑一遍 | 10–15 秒 |
| `phone-weekly.mp4` | 每週回顧頁，停留讓字能讀完 | 8–12 秒 |
| `phone-ask.mp4` | 秘書提問卡，點一個選項 | 8–12 秒 |
| `phone-care.mp4` | 照顧者版：關心的人 → 查看 → 近況 → 標記已讀 → 回填已聯絡 | 10–15 秒 |

錄法：手機內建螢幕錄影，直向全螢幕，不要露通知欄的私人訊息。檔名對就好，大小碼率隨意，我這邊會統一轉。
